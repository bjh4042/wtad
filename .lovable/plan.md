# 튜토리얼 4종 추가 구현 계획

`src/components/AndroidExplorer.tsx`에 4개 신규 학습 미션 흐름을 추가합니다. 기존 미션(0~48번)은 그대로 유지하고, 마지막 완료 메시지 앞(현재 48번 위치)에 신규 단계를 삽입한 뒤 완료 메시지를 마지막으로 밀어냅니다.

## 1. 알림 확인 및 지우기 (신규 미션 4단계)

- **새 미션 단계**
  1. 상단을 드래그하여 알림 패널 열기
  2. 카카오톡 알림 1건 확인(탭)
  3. 알림 한 개를 좌/우로 스와이프해서 삭제
  4. "모두 지우기" 버튼 눌러 전체 정리
- **UI**: 퀵패널 윗부분의 빈 영역에 노출되는 알림 카드 리스트 활용. 이미 `notifications` state가 있으므로, 퀵패널 열렸을 때 상단에 카드형 알림 영역을 분리 표시(좌/우 스와이프 = 포인터 드래그로 80px 이상 이동 시 삭제, "모두 지우기" 버튼 포함).

## 2. 앱 권한 관리하기 (신규 미션 4단계)

- **새 미션 단계**
  1. 설정 앱 실행
  2. 좌측 메뉴에서 "개인정보 보호" 선택
  3. 권한 관리자에서 KakaoTalk의 "위치" 권한 켜기
  4. 홈으로 돌아가기
- **UI**: `settings-menu-privacy`, `perm-KakaoTalk-위치` ActionTarget 추가. 기존 권한 화면 그대로 사용.

## 3. 구글 계정 추가 및 동기화 (신규 미션 8단계 — 실제 Google 로그인 경험)

- **시나리오**: 설정 → 계정 및 백업 → "계정 추가" → "Google" 선택 → Google 로그인 화면(실제 모방) → 이메일 입력 → 비밀번호 입력 → 동의 → 완료
- **가이드 자격증명** (튜토리얼 안내 텍스트 + 입력칸 placeholder로 안내)
  - 이메일: `wttest@gmail.com`
  - 비밀번호: `Ghkdlxld1!`
- **실감 디테일**
  - 흰 배경, 좌상단 4색 Google 로고(SVG), Roboto 느낌 sans-serif
  - "로그인" 제목, "Google 계정 사용" 부제
  - 이메일 input → "다음" 버튼 → 비밀번호 화면(이메일 chip + 아바타) → "다음" → 약관 동의 → 동기화 진행 스피너 → "환영합니다 wttest@gmail.com"
  - 실패가 없도록, 정확한 자격증명을 입력하지 않으면 빨간 경고 "이메일 또는 비밀번호가 올바르지 않습니다" 표시
  - 미션 안내 툴팁에 "ID: wttest@gmail.com / PW: Ghkdlxld1!" 문구 노출
- **새 미션 단계 8개**
  1. 설정 앱 실행
  2. "계정 및 백업" 선택
  3. "계정 추가" 버튼 누르기
  4. "Google" 선택
  5. 이메일(wttest@gmail.com) 입력 → 다음
  6. 비밀번호(Ghkdlxld1!) 입력 → 다음
  7. 동의 체크 → 동의함
  8. 동기화 완료 확인(완료 버튼)
- **신규 state**
  - `googleLoginStep: 'email' | 'password' | 'consent' | 'syncing' | 'done' | null`
  - `googleEmail`, `googlePassword`, `googleAccount` (성공 시 저장)
  - `settingsMenu === 'account'` 화면 구현 (현재 없음)

## 4. 앱 업데이트하기 (신규 미션 4단계)

- **새 미션 단계**
  1. Play 스토어 실행
  2. 우측 상단 프로필 아바타 클릭
  3. "앱 및 기기 관리" 메뉴 선택
  4. "모두 업데이트" 버튼 클릭 → 진행률 100% 후 완료 토스트
- **UI**: 기존 Play Store 화면에 상단 우측 아바타 추가, 클릭 시 시트 패널 슬라이드. "앱 및 기기 관리"에 업데이트 대기 3개(YouTube, 카카오톡, 크롬) 표시.

## 미션 배열 재구성

기존 `QUESTS` 마지막의 "모든 임무 완료" 항목 직전에 위 4개 그룹(4+4+8+4 = 20단계)을 순서대로 삽입. id는 순차 재번호. `targetId`는 위에 명시한 새 ActionTarget id 사용.

## 변경 파일

- `src/components/AndroidExplorer.tsx` — QUESTS 배열, 상태, 알림 패널 UI, 권한 화면 ActionTarget, 계정 설정 화면, Google 로그인 모달, Play Store 업데이트 화면 추가.

## 비변경 영역

기존 미션 0~47의 동작, 홈 화면 레이아웃, 다른 앱 동작은 그대로 유지.
