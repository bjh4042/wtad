# 안드로이드 탐험대 — 갤럭시탭 교실 개선본

학생이 갤럭시탭을 처음 사용하기 전에 직접 조작해 보는 브라우저 실습 앱입니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev
```

배포용 정적 파일 만들기:

```sh
npm run typecheck
npm test
npm run build
```

`dist` 폴더를 정적 호스팅의 배포 디렉터리로 사용합니다. 단일 페이지 React/Vite 앱이므로 서버 API나 Firebase 키는 필요하지 않습니다. dist/index.html을 파일로 직접 더블클릭하기보다는 HTTP 정적 서버로 실행하세요.

## 수업 운영

- 처음에는 미션 모드로 순서대로 학습합니다. 총 20단원, 171단계입니다.
- 한 차시에 모두 끝내도록 설계된 분량은 아닙니다. 기본 조작→사진/앱→파일/활용→안전 확인으로 나누어 진행하세요.
- 자유 연습에서는 어느 앱이나 연습할 수 있으며 미션 경험치는 올라가지 않습니다.
- 미션 센터는 제목 부분을 끌어 옮기거나 축소/닫을 수 있습니다.
- 현재 미션의 위치를 잃었다면 하단 '현재 미션으로'를 사용합니다. 화면을 준비할 뿐 정답 처리는 하지 않습니다.
- 진행 기록은 해당 브라우저의 해당 사이트에 저장됩니다. 다른 기기로 동기화되지 않습니다. 공용 태블릿에서는 학생이 바뀔 때 재시작을 사용하세요.
- 마지막 확인 문항은 여섯 상황을 모두 맞혀야 완료됩니다. 완료 기록은 실제 기기 숙달 보증이 아니므로 교사와 실제 갤럭시탭에서 재확인합니다.

## 원본 분석과 수정

원본은 104단계였지만 설정의 상당수 메뉴가 비어 있었고 갤러리의 공유/편집 등이 동작하지 않았습니다. 사진 삭제는 휴지통 안내와 달리 원본 배열에서 제거했고, 분할 화면은 앱 이름만 표시했습니다. 아무 Wi-Fi 비밀번호, 불필요한 위치 권한 허용, 단계 건너뛰기, 요약 자동 완료가 학습을 잘못 판정할 수 있었습니다.

이번 개선에서는 성공한 결과에만 경험치를 지급하도록 주요 실습을 수정하고, 중복 지급·미완료 단계 건너뛰기·마지막 완료 조건을 보강했습니다. 설정 및 기본 앱을 확장하고 사진/노트/연결/앱 상태를 복원하며, 저장값 손상과 이전 미션 ID 매핑을 처리합니다. 학습과 무관한 작동하지 않는 앱은 기본 홈에서 제거했습니다.

## 아이콘 및 One UI 화면 개선

홈·앱스·작업표시줄·최근 앱·알림·설정·스토어에서 같은 공통 아이콘을 사용합니다. 삼성 Try Galaxy와 공식 앱 배포 페이지의 원본 아트워크를 우선 사용하고, 투명 여백을 보정하여 같은 크기의 삼성 형태 아이콘 안에 표시합니다. Play 스토어는 Google 공식 심벌, 캘린더는 공식 모양을 참고한 실시간 날짜를 표시합니다. 연습용 가상 앱은 고유 벡터 아이콘을 사용합니다. 자산별 출처는 [ICON_SOURCES.md](docs/ICON_SOURCES.md)에 기록했습니다.

빠른 설정은 태블릿 우측의 420px 패널로 구성했습니다. Wi-Fi/블루투스 연결 타일, 원형 빠른 버튼, 밝기·음량 슬라이더, 편집·전원·설정 버튼을 배치했습니다. Wi-Fi 팝업에는 켜기/끄기 스위치, 보안 표시, 연결된 네트워크, 상세설정·완료 버튼을 적용했습니다. 작은 화면에서는 패널 폭을 화면에 맞추고 본문을 스크롤할 수 있습니다.

이번 화면 변경 후 홈·앱스 아이콘 크기, 빠른 설정과 Wi-Fi 창, 비밀번호 정답/오답, 밝기·음량·소리 모드, 알림 표시를 브라우저에서 확인했습니다. 연결한 Wi-Fi도 다시 선택해 같은 미션을 복습할 수 있습니다.

## 스마트폰 반응형 화면

767px 이하에서는 갤럭시 스마트폰용 세로 화면으로 전환됩니다. 화면 영역은 삼성 공식 Galaxy S26 사양의 1080×2340(19.5:9) 비율을 유지하며, CSS 크기는 접속 기기의 가로 폭에 맞춥니다. 물리 해상도를 1080 CSS 픽셀로 강제하지 않습니다. 참고: https://www.samsung.com/sec/smartphones/galaxy-s26/specs/

- 홈은 위젯 → 4열 앱 → 검색 → 즐겨찾는 앱 → 내비게이션 순서입니다. 320px 폭에서도 기본 앱 10개를 확인할 수 있습니다.
- 미션 안내는 기기 화면 위에, 접을 수 있는 기기 조작 도구는 화면 아래에 배치합니다. 높이가 낮은 내장 브라우저에서는 페이지를 세로로 스크롤하며 화면 비율을 유지합니다.
- 설정은 목록과 상세 화면을 한 화면씩 표시하고, 뒤로가기는 상세 → 목록 → 홈 순서로 동작합니다. 태블릿의 넓은 설정 화면은 유지합니다.
- 미션 목록은 하단 시트로 열리고, 조작 힌트는 화면 경계 안으로 위치를 보정합니다. 카메라·노트·시계의 좁은 화면 조작부도 조정했습니다.

데스크톱 브라우저의 320·360·390·430px 폭과 1366×768 태블릿 크기에서 홈 배치·화면 비율·가로 넘침을 확인했습니다. 설정 상세 → 목록 → 홈, Wi-Fi 창, 카메라 촬영·저장, 미션 목록도 확인했습니다. 실제 삼성 인터넷/Chrome의 소프트 키보드와 기기별 안전 영역은 실기기에서 최종 확인하세요.

## 시뮬레이션의 범위

실제 Android OS를 실행하지 않습니다. Wi-Fi·블루투스·권한·전원·설치·업데이트·공유·계정은 앱 내부 연습입니다. 실제 카메라나 학생 개인정보에 접근하지 않습니다. 사진은 가상 장면이며 스크린샷은 앱 안의 화면을 실제 이미지로 캡처합니다. 공유는 외부로 전송되지 않습니다. 시계 알림은 웹앱 화면을 열어 둔 동안만 작동합니다. 분할 화면은 계산기와 노트 조합을 연습합니다. 갤러리 편집은 표시 상태로 보관하며 원본 사진 파일을 외부로 내보내는 기능은 포함하지 않습니다.

연습 계정은 student@example.invalid / Practice123!, Wi-Fi는 tablet1234, PIN은 482716입니다. 실제 계정이나 비밀번호를 입력하지 않습니다.

## 검증 범위

TypeScript 검사, 정적 빌드, 자동 회귀 테스트를 실행합니다. 브라우저에서 잠금 해제→Wi-Fi 연결의 정답/오답 처리, 설정 밝기와 진행 복원, 카메라 촬영→갤러리 삭제→복원, 화면 캡처 저장, 앱 설치→실행, 폴더 생성, 타이머 시작을 확인했습니다.

171단계 전체를 모든 기기에서 연속 조작한 검증은 하지 않았습니다. 교실 공개 전 실제 갤럭시탭의 Chrome/삼성 인터넷, 가로/세로 화면, S Pen/터치에서 마지막 수업 리허설이 필요합니다.
