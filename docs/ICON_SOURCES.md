# App icon sources and fidelity notes

Retrieved and visually checked on 2026-11-02. These assets identify the real apps used in an educational Galaxy tablet simulator. App names and artwork belong to their respective owners. Assets are bundled locally; the app does not depend on remote image URLs at runtime.

## Authoritative visual reference

Samsung's [Try Galaxy](https://trygalaxy.com/) currently presents the Galaxy S26 / Z Fold8 experience and uses the `qhb8` default theme. The live, public app bundles explicitly reference the theme icon paths below. Camera, Gallery, Settings and other Samsung app artwork were taken directly from that official simulator. Samsung's [One UI icon background guidance](https://developer.samsung.com/one-ui/iconography/background.html) describes rounded square icon backgrounds; the shared renderer normalizes their presentation.

For comparison, Samsung's [S26 camera support guide](https://www.samsung.com/us/support/troubleshoot/TSG10013051/) includes this [official home screen screenshot](https://image-us.samsung.com/SamsungUS/support/solutions/mobile/phones/galaxy-s/s26/MOB_PH_GS_S26_Switch-to-Night-mode-1.jpg).

Current app listings can update independently of device firmware. Authentic current Galaxy Store artwork was preferred for Calculator, Clock, Samsung Notes, Galaxy Store and Gaming Hub. Current Try Galaxy artwork was preferred for My Files where the store listing still used the older flat style. This is a faithful training simulation, not an assertion that every model, region, theme and app revision has pixel-identical artwork.

## Normalization and dynamic icons

- Every downloaded image was visually inspected. The old generic camera/globe/Google Photos substitutions are not used by the shared Samsung icon component.
- Transparent bounds were measured with Pillow. Most authentic Samsung silhouettes already fill their canvases. Gallery and Health contained one fully transparent pixel column on the right; that column was cropped without scaling or changing the artwork. Remaining files retain their original artwork and proportions.
- Samsung Notes was converted losslessly from the official 512 px PNG to WebP to preserve the renderer's existing filename. Other source files retain their downloaded format.
- White background Google app icons intentionally retain the official internal logo padding. They belong inside the same visual rounded square as the Samsung apps; enlarging only the inner triangle, G, or YouTube play symbol would change the actual icon design.
- `playstore-symbol.svg` contains Google's exact four colored paths copied from the publicly served Google Play page. It is rendered within the shared white launcher tile, using the official Samsung home screen as a placement reference.
- `calendar.webp` is Samsung's canonical static Monday 3 reference. The shared component may reproduce the header/date geometry as SVG to display the simulator's real weekday and date.
- `sources.json` maps only the final included assets to their publisher page and exact original URL. The unused low-resolution candidates and superseded icons were removed.
